Webhook secret

A shared password for webhooks. Sonarr, Radarr, Plex, Emby, Jellyfin and your own scripts send it so Reprise knows a request is genuine. Setup steps for each are on the Automation page.

How it is sent

Scripts and apps send it as an X-Auth-Token or Authorization: Bearer header. Plex puts it in its webhook address as ?token=.
