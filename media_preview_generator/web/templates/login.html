Forgot your password?

There's no email reset: only someone with access to this server can get you back in. Open the container's console (on Unraid: Docker tab, the Reprise icon, Console) and run one of these:

Choose a new password for the same account

python3 -m media_preview_generator.web.account_cli reset-password

Start over, with a new username too

python3 -m media_preview_generator.web.account_cli reset-account

Both take effect straight away and sign every browser out. Your webhook secret, servers and results are not touched. Without a console, deleting auth.json from Reprise's config folder does the same as the second one.
