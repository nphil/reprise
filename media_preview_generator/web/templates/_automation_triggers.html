Connect Sonarr or Radarr

Paste this address into Sonarr or Radarr (the “*arr” apps that download your shows and films) and Reprise starts on each new episode or film right away. This kind of address is called a webhook: a message one app sends another when something happens.

How to set it up in {{ app[1] }}
  1. Go to Settings → Connect → + → Webhook
  2. Set Name to Reprise
  3. Set URL to the address above
  4. Under Events, tick {{ app[2] }} and {{ app[3] }}
  5. Authentication:
    • Username/Password: leave Username blank and put your webhook secret in Password.
    • Headers (if your form has this field): add X-Auth-Token = your webhook secret.
  6. Click Test, then Save
{% endfor %}
The webhook secret is a password that proves a request really comes from your app. Show, copy or change it under Settings → Connections.

A different wait for each app

Reprise waits a short time after a new file arrives (set in Webhook settings below). To change that for one app, add ?delay=30 to the end of its address (30 seconds; any number from 1 to 3600 works). If the address already contains a ?, add &delay=30 instead.

Other ways to start previews
Tdarr, FileFlows or your own script
Tdarr and FileFlows are tools that convert video files. They can tell Reprise when a file is ready.

Media you add to Plex by hand
Reprise can set up the Plex side by itself: in Connections, edit your Plex connection and open Webhook & Scanner.
Open Connections
Media you add to Emby by hand
Emby (with Premiere) can send webhooks by itself.
How to set it up
Emby Dashboard → Webhooks → Add Webhook. Point it at https://<your-host>/api/webhooks/incoming?token=<webhook secret> and tick Library → New Media Added.
Media you add to Jellyfin by hand
Install Jellyfin’s official Webhook plugin and use the same address as Emby.
How to set it up
Jellyfin Dashboard → Plugins → Catalog → Webhook. Add a Generic destination with the URL https://<your-host>/api/webhooks/incoming?token=<webhook secret> and subscribe to Item Added.
Replaced files need Sonarr or Radarr

Plex, Emby and Jellyfin only announce brand-new items. When Sonarr or Radarr swaps in a better copy of a file, use their On Upgrade event (already ticked in the steps above).

Why this happens
When Sonarr or Radarr upgrades a file in place, your media server keeps the same library item, so it does not count the new file as “added” and never sends its own webhook. The Sonarr/Radarr upgrade event works whichever media server you use.
Custom webhook Tdarr, FileFlows, scripts

For any tool that can send a web request. Send it the path of a finished file and Reprise handles it just like a Sonarr or Radarr import.

To limit this address to one server or set a different wait, use More options in the Sonarr and Radarr card above.
What to send: one file 
{% raw %}{
  "file_path": "/media/movies/Movie (2024)/Movie.mkv"
}{% endraw %}
What to send: several files 
{% raw %}{
  "file_paths": ["/media/tv/Show/S01E01.mkv", "/media/tv/Show/S01E02.mkv"],
  "title": "Optional display label"
}{% endraw %}

To check the connection without starting any work, send {% raw %}{"eventType": "Test"}{% endraw %}.

Tdarr setup
  1. Open your Tdarr Flow and add a Send Web Request plugin after your transcode step
  2. Set Method: POST
  3. Set Request URL: copy the Custom Webhook URL above
  4. Set Request Headers: 
    {% raw %}{
  "Content-Type": "application/json",
  "X-Auth-Token": "YOUR_WEBHOOK_SECRET"
}{% endraw %}
  5. Set Request Body: 
    {% raw %}{"file_path": "{{{args.inputFileObj._id}}}"}{% endraw %}
  6. Save the flow

The {% raw %}{{{args.inputFileObj._id}}}{% endraw %} template is replaced by Tdarr at runtime with the full file path of the transcoded file.

FileFlows setup

In FileFlows, install the Web plugin (Plugins page → search "Web") so the Web Request node becomes available, then add two nodes to the end of your flow:

  1. Add a Set Variable node just before the Web Request node — FileFlows doesn't expose a built-in "final output path" variable, so build it from the folder + final filename + extension:
    • Variable: output_file
    • Value: {% raw %}{folder.Orig.FullName}/{file.NameNoExtension}{ext}{% endraw %}
  2. Add a Web Request node after the Set Variable node:
    • Method: POST
    • URL: copy the Custom Webhook URL above
    • Content Type: JSON
    • Headers: key X-Auth-Token, value YOUR_WEBHOOK_SECRET
    • Body: 
      {% raw %}{"file_path": "{output_file}"}{% endraw %}
  3. Save the flow

The {% raw %}{output_file}{% endraw %} placeholder is substituted by FileFlows at runtime with the absolute path of the file as it exists at the end of the flow (after any rename / re-extension steps).

curl example 
{% raw %}curl -X POST "http://your-server:8080/api/webhooks/custom" \
  -H "Content-Type: application/json" \
  -H "X-Auth-Token: YOUR_WEBHOOK_SECRET" \
